# Contributing to Agent Tool Hub

Thanks for improving the utilities.

## Before opening a pull request

1. Open an issue describing the problem or feature, unless the change is a very small documented fix.
2. Make a focused branch with one logical improvement.
3. Run the affected `.html` page and verify the behavior with realistic, **fictional** sample data.
4. Check that links in `index.html` still reach the correct tools.
5. Verify desktop and narrow screen layouts, keyboard navigation, light and dark themes.
6. Check the browser console for JavaScript errors.
7. Do not commit credentials, customer information, service tokens or private work documents.

## In your pull request

Describe the user facing change, test steps, and known limitations. For UI changes, include a before/after screenshot if available. Avoid changing third party branding or claiming the project is endorsed by any service provider.

The project currently has no build pipeline. Contributions should keep the standalone HTML workflow usable unless a migration has been discussed.
